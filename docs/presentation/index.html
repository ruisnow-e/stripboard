From the Cost Matrix to the Shooting Order

The geographic layer gives the cost of every move. Choosing the order is NP-hard — and greedy has no guarantee.
Sometimes optimal, sometimes 28% off — and greedy cannot tell you which.

One Method for Any Size

A minimum spanning tree (Kruskal + union-find) partitions the map; dynamic programming then solves inside each region and across them.
The exponents sit on region size (≤ 10) and region count (≤ 13), not on the number of locations.

Dynamic Programming over Subsets

dp[S][v]  = cheapest way to have shot the set S and be standing at v  — the same 4-node graph we just traced
Optimal substructure and overlapping subproblems — the subproblem is indexed by a subset instead of a prefix.
13 states instead of 6 orders here — 11,265 instead of 39,916,800 at twelve locations.

Summary

Geographic layer — Dijkstra + greedy
  • Modeled film locations as terrain-weighted spatial graphs using a composite weight formula encoding distance, elevation, and terrain difficulty
  • Implemented Dijkstra's algorithm with Python's heapq; all-pairs cost matrix feeds the scheduling layer as C_loc
  • Greedy Nearest-Neighbor is fast (O(k²)) and gives a valid schedule, but no optimality guarantee
Scheduling layer — MST + dynamic programming
  • Solved the shooting order exactly wherever that is affordable, and by MST partitioning where it is not — one method, one code path
  • 5.3–10.7% below the greedy draft on 90 real filming locations at three geographic scales
  • 1,160 cases checked against brute-force enumeration, 0 disagreements
Limitations
  • The geographic layer's graphs are synthetic; the scheduling layer's 90 locations are real, but transit is great-circle distance, not real roads
  • Undirected graph; real transit costs are often asymmetric
  • The partition is the method's only approximation, and above 20 locations its cost cannot be measured
Future Work
  • Extend to directed graphs
  • Apply A* search with geospatial heuristic for large-scale graphs
  • Branch-and-bound to push the exact ceiling past 20 locations
